# PH Pathology Registry Add-On 0.1.1

- Adds a Pathology Registry link to the PH Alpha 0.4.0 navigation.
- Adds Biopsy / Responsible Provider.
- Adds Reviewed / Closed By.
- Adds Entered By for each update entry.
- Preserves unlimited chronological update entries per biopsy finding.
- Uses synthetic patient IDs only in the public/browser module.
- The companion Excel workbook is de-identified and contains no patient-name column.
