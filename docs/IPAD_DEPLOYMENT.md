# Publish for Mallory on iPad

The application is one self-contained `index.html` file.

## GitHub Pages path

1. Keep your private `ph-platform` repository as the master.
2. Create a separate reviewer repository containing only synthetic reviewer files.
3. Copy `index.html` into that reviewer repository.
4. Enable GitHub Pages from the reviewer repository settings.
5. Send Mallory the generated web address.
6. On iPad, she can open the link in Safari and use Share → Add to Home Screen.

Do not publish legal documents, confidential architecture, passwords, credentials, or real patient information.
